# GUTS CAMERA

iPhone用のゴルフスイング分析Webアプリ（PWA）です。
動画を取り込み、補助線・スロー再生・コマ送りで分析し、iPhoneの中に保存できます。
サーバー・ログイン・有料APIは使いません。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| index.html | 画面の構造 |
| style.css | デザイン |
| app.js | アプリの動作すべて |
| manifest.json | ホーム画面に追加したときの設定 |
| service-worker.js | オフライン対応と更新の案内 |
| icon-180.png / icon-192.png / icon-512.png / icon-maskable-512.png | アプリアイコン |

フレームワークやビルドは使っていません。ファイルをそのまま置くだけで動きます。

アイコンを `icons/` フォルダに入れず同じ階層に置いているのは、iPhoneのSafariからGitHubへ
アップロードするときにフォルダごと選べないためです。全ファイルを一度に選んでアップロードできます。

## iPhoneだけで公開する手順（GitHub Pages・無料）

※ GitHubの画面は変更されることがあります。メニューが見つからないときは、Safariのアドレスバーの
「ぁあ」→「デスクトップ用Webサイトを表示」に切り替えてください。

1. ZIPを「ファイル」アプリでタップして展開する
2. Safariで github.com を開き、アカウントを作成してログインする
3. 「＋」→「New repository」→ 名前を `guts-camera` などにして **Public** で作成する
4. 作成直後の画面にある「uploading an existing file」を開き、展開したファイルをすべて選んで「Commit changes」
5. リポジトリの「Settings」→「Pages」→ Source を「Deploy from a branch」、Branch を「main」「/ (root)」にして保存
6. 数分後に `https://（ユーザー名）.github.io/guts-camera/` をSafariで開く
7. 共有ボタン →「ホーム画面に追加」

無料プランのGitHub Pagesは公開（Public）リポジトリが対象です。アプリのコードは公開されますが、
動画はiPhoneの中だけに保存され、GitHubには送られません。

## 更新のしかた

GitHubでファイルを開き、鉛筆アイコンから編集して「Commit changes」するだけです。
アプリを開き直すと、裏で新しいファイルを確認し「新しいバージョンがあります」と表示されます。
「更新」を押すと切り替わります（service-worker.js を書き換える必要はありません）。

## 使い方の要点

- **カメラで撮影**：「撮影する」→ 撮影方向を選ぶ →「カメラで撮影」。アプリ内のカメラで録画し、
  停止するとそのまま分析画面に進みます。画面上部に実際の解像度とフレームレートが表示されます。
  左下のボタンで 60fps／30fps、右下のボタンでカメラの前後を切り替えられます。録画は最長10分です（画質は短い録画と同じなので、長く撮ると容量が大きくなります。10分で約1〜1.5GB）。
  インカメ（前面カメラ）では**セルフタイマー**が使えます。録画ボタンを押すと、画面の中央に 5・4・3・2・1 と出て、5秒後に録画が始まります。
  数えている間にもう一度録画ボタンを押すと取り消せます。録画ボタンの上の「タイマー」で入り・切りを切り替えられます（最初は入り）。
  右上の「ガイド線」で、構図合わせ用の線（中央線・頭の高さ・足元の高さ・対角線）を出したり消したりできます。
  ガイド線は、カメラを開くたびに必ず表示された状態から始まります（前回消していても）。
  線は画面に重ねて表示するだけで、録画には写りません。線の範囲は、下のボタンが並ぶ部分の上までです。
  「後方」から縦画面で撮影するときは、構えの目安も一緒に出ます：構えた人の形（グレーのふちの、うすいシルエット。これに体を合わせる）、
  蛍光イエローの丸（手元＝グリップの先とシャフトの境目を合わせる。画面の左右の中央、縦の中央線の上にあります）、
  蛍光イエローの丸で交わる白いバッテン（下は範囲の両角へ、上は左右の端の同じ高さへのびる線）。
  中央線の上には、目標のイメージとしてグリーンと旗（うすい緑のグリーン・白いポール・赤い旗）と、旗の右に赤い札「目標」が出ます。
  カメラ → 手元 → 目標 は白い点線でつながり、目標のカップに矢印の先が刺さっています。録画を始めるまでは、矢印がカメラから手元へ、手元から目標へ流れるように動きます。
  中央線のいちばん下にはカメラのマークがあり、カメラ → 手元の蛍光イエローの丸 → 旗 が一直線に並びます。
  大事な2点を①②の札で示します：①「手元を合わせる」（蛍光イエローの札、手元の丸の右）、②「構えた手の高さで撮影」（赤い札、カメラのマークの上）。
  録画を始めるまで、札の白い枠が点滅します。②の札はカメラ画面だけに出ます。
  カメラ画面では録画を始めるまで、蛍光イエローの丸が1秒ごとに大きく点滅し（太さ・大きさが変わる）、外へ広がる波紋が2重に出ます。丸の右には①の札が出ます
  （録画ボタンを押すと止まります。分析画面のガイド線では点滅しません）。
  このときは、角から角への対角線は出しません。
  「正面」からの撮影と横画面では、構えの目安は出ません。目安は右打ちの構え（画面の右を向く）を基準にしています。
  録画ボタンの上に「.5／1／Max」が出ます（使える端末のみ）。.5 が広角、Max は3倍（カメラの上限が3倍より小さいときはその上限）です。
  プレビューを2本指でつまむか、ボタンの並びを指でなぞると、広角〜最大までなめらかに変えられます。
  カメラを開くときは、いつも広角か標準（1倍）から始まります。
- **取り込み**：「動画を取り込む」。より細かくコマ送りしたいときは、iPhone標準のカメラでスロー撮影した動画を
  「ファイル」アプリに保存し、「ファイルを選択」から読み込んでください
  （写真ライブラリから選ぶと、iOS側で画質が下げられる場合があります）。
- **再生モード／描画モード**：ツールを押すか、引いてある線や枠に触れると描画モードになり、動画は自動で止まります。
  線や枠は、触れてそのままドラッグすれば動かせます。
  再生ボタンを押すと再生モードに戻ります。
- **シャフトライン**：2点をタップ。線をタップして選ぶと、端の丸で角度、線の途中で位置を動かせます。
- **スウェーライン**：左足の外側、右足の外側の順にタップすると、縦線が2本引かれます。
  引いたあとはシャフトラインと同じように、端の丸で向きや長さ、線の途中で位置を動かせます。
- **ボールライン**：ボールの位置を1回タップすると、まっすぐな縦線が1本引かれます。動かし方は同じです。
- **線の太さ**：最初は「細」です。「色・太さ」で変えられます。
- **前後カット**：下の「前後カット」を押すと、「ここから」「ここまで」の段になります。
  再生やコマ送りで使いたい最初のコマに合わせて「ここから」、最後のコマに合わせて「ここまで」を押します。
  シークバーには使う範囲が黄色で出ます。赤い「完了」を押すと、再生・コマ送り・シークバーがその範囲の中だけになります。
  動画ファイル自体は切らないので、「全体に戻す」でいつでも元に戻せます（保存容量は減りません）。
  一覧のサムネイルは「ここから」のコマになります。
- **2本指で拡大**：分析画面で動画を2本指で広げると拡大（最大5倍）、狭めると元の大きさに戻ります。
  2本指のまま動かすと、拡大した位置を動かせます。線や枠も一緒に拡大されるので、拡大したまま引いたり動かしたりできます。
  録音で作る解説動画には、拡大は反映されません（元の大きさで記録されます）。
- **頭の枠**：押すと枠が出ます。枠の中をドラッグで移動、四隅の丸で大きさを変えます。
- **分析画面（縦画面）**：動画を画面いっぱいに表示し、上の表示と下の操作パネルを動画に重ねています。
  描画モードでも同じ大きさで表示します。操作パネルに隠れた部分に線を引きたいときは、
  いったん上のほうに引いてから、線をドラッグして動かしてください。
- **分析画面のガイド線**：右上の「ガイド線」を押すと、カメラ画面と同じガイド線（構えの目安を含む）を動画に重ねて表示します。
  最初は表示されていません。もう一度押すと消えます。録音で作る解説動画には入りません。
- **動画をタップ**：操作パネルを隠して動画全体を表示します（再生モードのとき）。
- **続けて撮影**：分析画面の左上（戻るボタンの隣）の黄色い「撮影」ボタンを押すと、同じ撮影方向のまま次の動画を撮影できます。
- **解説動画（録音）**：「撮影」ボタンの隣の「画面録画」ボタン（赤い丸のマーク）を押すと、マイクで声を録りながら、
  分析画面の映像と補助線を1本の動画にします。再生・コマ送り・線を引く／動かす操作が、そのまま動画になります
  （操作パネルやボタンは動画に入りません）。赤いボタンをもう一度押すと終了し、
  そのまま保存先を選ぶ画面（iPhoneの共有画面）が出ます。「ビデオを保存」で写真アプリ、LINEなどのアプリも選べます。
  保存先を選ばずに閉じた場合や、共有画面を出せなかった場合は、動画が消えないように確認の画面が出て、
  もう一度「共有・保存」を選ぶか、「アプリに保存」（マイスイングに「解説 …」として追加）ができます。
  1回の録音は最長3分、動画の大きさは長辺1280ピクセルまでです。元の動画は変わりません。
- **分析画面の上のボタン**：「撮影」と「画面録画」は同じ大きさです。動画のタイトルは分析画面には表示しません
  （タイトルは一覧と、「編集」を押した画面で確認できます）。
- **診断情報**：ホーム画面の一番下の「GUTS CAMERA v…」をタップすると、画面サイズなどの情報を表示します
  （表示の不具合を調べるときに使います）。
- **コマ送り**：ボタンの長押しで連続して送れます。
- **保存**：保存済みの動画は、補助線の変更が自動で保存されます。
- **iPhoneのアルバム（写真アプリ）への保存**：撮影した動画は、まずアプリに保存します。そのあと必要なときに、
  分析画面の右上「アルバム」（「編集」の下）か、一覧の各動画の保存マーク（ごみ箱の左）を押すと、iPhoneの共有画面が出ます。
  「ビデオを保存」を選ぶとアルバムに入ります。アプリに保存する前の動画には「アルバム」は出ません。
  アルバムに入る動画は、アプリに保存した動画と同じものです（画質は撮影したときのまま）。

## 知っておいてほしい制約

- **コマ送りは近似です。** ブラウザでは動画の正確なコマ位置を取得できないため、
  「1コマ分の時間だけ進める」方式です。コマ数（fps）は再生時の情報から推定し、
  画面の「コマ送り ○fps」から手動でも選べます。動画によっては同じコマが続いたり、1コマ飛ぶことがあります。
- **アプリ内カメラは 30fps または 60fps です。** 120/240fps のスロー撮影はブラウザからはできません。
  1080p・60fps を優先して要求し、端末が対応していない場合は自動で下げます。実際に何が得られるかは端末によります。
- **スロー撮影（120/240fps）の動画**は、写真ライブラリから選ぶとiOS側で変換・圧縮されて渡されることがあります。
  「ファイル」アプリ経由なら元のまま渡されると報告されていますが、実機での確認が必要です。
- **タップでのピント合わせ**は、ブラウザのカメラ機能が対応している端末でだけ働きます。
  対応している場合は、プレビューをタップした位置に黄色い枠が出てピントが合います。
  対応していない端末（確認できた資料では iPhone の Safari は非対応）では、カメラの自動ピントのままです。
- **ズーム（広角〜標準）**は、端末とiOSのバージョンによって使える範囲が違います。使えない端末ではボタンを表示しません。
  拡大（デジタルズーム）は画像を引き伸ばすため、倍率が上がるほど画質が下がります。粗くなりすぎないよう3倍までにしています。
  広角が別のカメラへの切り替えになる端末では、つまむ操作ではカメラを切り替えず、「.5」「1」のタップで切り替えます。
  広角は、標準より画質やフレームレートが下がる場合があります。
- **カメラの許可**：初回に許可を求められます。拒否した場合は、iPhoneの「設定」でSafariのカメラを許可してください。
- **0.125倍などの低速再生**は端末・iOSのバージョンによって対応が異なる可能性があります。
  対応していない場合や、指定どおりの速度で再生できていない場合は画面に案内を表示します。
- **アプリ内の保存は永久保存ではありません。** iOSの容量整理やSafariのデータ削除で消えることがあります。
  ホーム画面に追加して使い、元の動画は「写真」アプリにも残してください。
- **撮影・取り込みした動画の音声は再生しません**（スロー再生時の不具合を避けるため、消音です）。
  アプリで作った声入りの解説動画だけは、音を出して再生します。
- **解説動画の録音**は、ブラウザの録画機能を使うため、端末やiOSのバージョンによっては使えない、
  または映像が正しく記録されない可能性があります（iPhoneの実機では未確認です）。
  録音中にアプリを離れると、そこまでの分で終了します。マイクを許可していない場合は、声なしの動画を作れます。
- 補助線は動画に焼き込まず、別データとして保存しています。線入りの動画が必要なときは、解説動画（録音）で作れます。

## まだ入っていない機能

- 2画面比較（第二段階として追加予定）
- アプリ内カメラでの120/240fps撮影（ブラウザの制約のため不可）
